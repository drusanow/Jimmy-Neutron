## This fork: additions on top of 1.5f

**Not yet tested on hardware.** Everything below builds, and the DSP parts are checked
by host-side tests (`make test`), but nobody has run this build on a Neutron yet.
Back up your current firmware first (see *Returning to the original firmware*).

### New features

| Feature | How to use it |
|---|---|
| **Smoother oscillator shape morph** | Always on. Shape knobs are filtered, the crossfade cv is interpolated (~40x finer steps), and the wave switch has hysteresis, so a knob resting between two waves no longer clicks. |
| **Shape drift** (slow, subtle movement between waveforms) | Hold **OSC SYNC** and turn **LFO SHAPE** = drift depth (fully left = off), **LFO RATE** = drift speed (0.03–5 Hz). OSC 2 drifts at a different rate than OSC 1. |
| **Wavetable oscillator** (new LFO mode 7) | Hold **LFO SYNC**, press **OSC 2 RANGE** until all LFO leds except the 2nd one are lit. Patch **LFO out** into the audio path. **LFO SHAPE** morphs through 8 waves (sine, organ, "ah", "ee", hollow, comb saw, bell, resonant), **LFO RATE** = pitch offset. Band-limited, so high notes stay clean. The LFO sync input hard-syncs it (edge set with LFO SYNC + FILTER MODE). |
| **Third oscillator tuning** (LFO mode 3 "monophonic" and the wavetable mode) | Hold **LFO SYNC** and press **PARAPHONIC** = follow OSC 1 instead of OSC 2 (led lit = OSC 1). Hold **LFO SYNC** and press **KEY TRK** = LFO RATE snaps to semitones (led lit = on), so you can dial exact intervals: ±12 semitones, or ±40 with KEY SYNC lit. |
| **USB MIDI** | Plug in USB: the Neutron appears as a class-compliant MIDI device ("Neutron neutr_cube"), no driver needed. It plays from USB just like from DIN: notes, pitch wheel, mod wheel, breath, sustain, aftertouch, all notes off, MIDI clock/start for LFO sync, on the channel set by the back panel switches. Everything arriving at DIN MIDI IN is also sent to the computer (a keyboard plugged into the Neutron shows up in your DAW). |
| **Bootloader shortcut** | Hold **OSC SYNC + FILTER MODE** while powering on. All leds light and the Neutron enters the STM32 USB DFU bootloader, ready for flashing. Power cycle to leave. |

The new settings are saved with the usual PARAPHONIC + OSC SYNC. Settings saved by 1.5f
are kept (calibration is not lost); the new options start at their defaults.

USB MIDI does not speak Behringer's SysEx protocol, so the SynthTool / Neutron app can not
edit this firmware's settings. It uses the pid.codes test USB ID (1209:0001) rather than
Behringer's. The USB stack is [TinyUSB](https://github.com/hathach/tinyusb) 0.17.0 (MIT),
vendored in `neutr_cube/Middlewares/tinyusb`.

Fixed along the way: poly LFO initialised a 6th voice that does not exist (memory
corruption), poly voice stealing could index past the voice array, and the old classic
LFO led code could write outside its buffer.

### Building

```
cd neutr_cube
make            # build/neutr_cube.elf .hex .bin .dfu  (needs arm-none-eabi-gcc, python3)
make test       # host-side tests of the shape, pitch, wavetable and USB MIDI code (needs gcc, python3 + numpy)
```

Wavetables are generated by `tools/gen_wavetables.py` – edit the wave definitions there and
rerun it to make your own set.

### Flashing

Put the Neutron in bootloader mode: hold the **BOOT** button on the back while powering on,
or use the OSC SYNC + FILTER MODE shortcut above (only works once this firmware is installed). Then:

- Linux / macOS: `dfu-util -a 0 -s 0x08000000:leave -D build/neutr_cube.bin`
- Windows: ST DfuSe or STM32CubeProgrammer with `build/neutr_cube.dfu` (see `neutr_src/manual.txt` about drivers)

Flashing erases the oscillator tuning stored by other firmwares – run auto-tune afterwards
(hold both RANGE buttons, press KEY TRK) and save.

### Returning to the original firmware

The STM32 ROM bootloader can not be erased, so this always works:

1. Enter bootloader mode (BOOT button, or OSC SYNC + FILTER MODE at power on).
2. Either run Behringer's Neutron firmware updater (it uses the WinUSB/Zadig driver on Windows),
   or flash the original 1.2.6 dump in this repo:
   `dfu-util -a 0 -D neutr_cube/Neutron_Dfuse_rom_dump_1_2_6.dfu`
   (or with DfuSe on Windows), or a dump you made of your own unit.
3. Recalibrate the pots as described under *RETURNING TO ORIGINAL STATE* in `neutr_src/manual.txt`.
